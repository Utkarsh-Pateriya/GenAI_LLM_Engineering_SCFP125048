# Lab Booking AI Assistance

## Overview
This project focuses on building an AI-powered assistant for a diagnostic laboratory. It helps users explore available lab tests, check time slots, book or cancel appointments, and get general health information.

## Key Features
- View available laboratory tests and prices.
- Check test availability and time slots.
- Book and cancel appointments with user approval.
- View personal booking history.
- Answer general health-related questions using web search.
- Maintain conversation memory and protect user privacy.
- Handle errors and evaluate different user scenarios.

## Technologies Used
- Python
- LangChain
- Groq API
- SQLite Database
- Web Search
- Kaggle Notebook

## Learning Outcome
Learned how to build an AI agent using tools, database operations, memory, web search, approval workflows, and validation to manage laboratory test bookings safely.
