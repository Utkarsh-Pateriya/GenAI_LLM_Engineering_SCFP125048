# Lab 3 — Prompt Engineering

This lab focuses on designing effective prompts to perform different tasks using Large Language Models (LLMs).

## Exercises Included

1. Doctor Summary Generator
2. Review Classifier
3. Resume Field Extractor
4. Customer Support Reply Generator
5. Multi-language Translator
6. Iterative Content Refiner

**Total Exercises: 6**

## Objective

The objective is to understand how prompts can guide an LLM to generate structured summaries, classify reviews, extract information, create replies, translate text, and improve content through multiple rounds.
