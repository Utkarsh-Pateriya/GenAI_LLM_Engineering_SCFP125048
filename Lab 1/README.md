# Lab 1 — Introduction to LLMs

This lab covers the basic concepts of Large Language Models (LLMs), model selection, tokenization, local execution, and chatbot development.

## Activities Included

1. Explore LLM models on Hugging Face
2. Perform tokenization experiments
3. Run an LLM using Google Colab GPU
4. Check whether a computer can run an LLM
5. Run an LLM locally using Ollama
6. Use an LLM through an API or inference provider
7. Compare local, Colab, and API execution
8. Experiment with temperature settings
9. Build a mini chatbot
10. Customize the chatbot with a specific role

**Total activities: 10**
