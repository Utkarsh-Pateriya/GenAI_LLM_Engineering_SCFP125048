# Lab 5 — Workflow Design with LLMs

This lab covers the design of multi-step LLM workflows using prompt templates and output parsers. Each exercise demonstrates how the output of one step can be passed to the next step in a structured format.

## Exercises Included

1. Customer Review to Support Ticket Pipeline
2. Research Paper Abstract to Layperson Summary Pipeline
3. Interview Transcript to Candidate Scorecard Pipeline
4. Outdoor Event Plan to Weather-Adjusted Recommendation Pipeline
5. Customer Support Chat Log to Escalation Report Pipeline
6. Workout Goal to Weekly Plan Pipeline

**Total Exercises: 6**

## Objective

The objective is to learn how to combine `PromptTemplate`, `ChatPromptTemplate`, `PydanticOutputParser`, and `StrOutputParser` to build organized and reusable LLM workflows.
