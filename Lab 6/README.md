# Lab 6 – Tools & Tool Calling with LLMs

## Overview
This lab focuses on using tools with Large Language Models (LLMs) to perform different tasks. It explores how an LLM can call external functions and use their results to generate useful responses.

## Exercises
1. Order Status Lookup Tool
2. Loan EMI Calculator
3. Unit Converter Toolkit
4. Weather-Based Outfit Recommendation
5. Async Product Stock Checker
6. Expense Splitter
7. Trip Cost Estimator
8. Health Metrics Toolkit
9. Smart Meeting Scheduler
10. Restaurant Recommendation Assistant

## Technologies Used
- Python
- Google Colab
- LangChain
- Groq API
- Pydantic

## Learning Outcome
Learned how to create custom tools, use structured inputs, perform asynchronous tool calls, and connect LLMs with external functions to build practical AI assistants.
